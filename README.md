# Спина — тренировки

Минималистичное веб-приложение (PWA) для домашних тренировок спины: блоки упражнений по кругу, один тап на подход, таймер для упражнений на время, серия дней, календарь и оценка самочувствия после тренировки.

## Устройство

Статический сайт без сборки и без серверной части:

| Файл | Назначение |
|---|---|
| `index.html` | всё приложение (разметка, стили, логика) |
| `manifest.webmanifest` | название, цвета и иконки для установки на экран |
| `sw.js` | service worker: работа без интернета |
| `icon*.png`, `icon.svg` | иконки |

Данные (программа, история, серия) хранятся в `localStorage` на телефоне. Сервер только отдаёт файлы. Для переноса есть экспорт и импорт в файл.

Все пути относительные, поэтому приложение работает и на домене, и на поддомене, и в подпапке.

## Требования к хостингу

- **HTTPS обязателен**: без него не работают установка на экран и режим без интернета.
- Подойдёт любой веб-сервер, который отдаёт статику (nginx, Apache, хостинг с панелью).

## Обновление

После изменений поднимите версию кэша в `sw.js` (`spina-v1` → `spina-v2`), иначе телефон продолжит показывать старую версию из кэша. Новая версия появится при втором открытии приложения.
